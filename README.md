# Red Social Pascualina

## Integrante

* Brandon Montoya Vidales

## Descripción

Proyecto académico de la asignatura Bases de Datos I de la Institución Universitaria Pascual Bravo.

El proyecto consiste en el diseño de un modelo lógico y la normalización de una base de datos para una red social estudiantil llamada Red Social Pascualina. El sistema contempla estudiantes, publicaciones, comentarios, intereses, habilidades, grupos, eventos, seguimiento y mentoría.
